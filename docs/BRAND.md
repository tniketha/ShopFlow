# ShopFlow brand assets

ShopFlow's mark combines a shopping bag with an S-shaped path ending in a forward arrow. It connects the store identity with the movement of products, stock and sales. The app uses the mark on sign-in, navigation and loading screens, with matching browser and Apple touch icons.

## Files

The reusable files are in `apps/web/public/brand/`:

| File                                                   | Use                                           |
| ------------------------------------------------------ | --------------------------------------------- |
| `shopflow-mark.svg`                                    | Scalable mark on light surfaces               |
| `shopflow-mark-light.svg`                              | Scalable reverse mark on dark surfaces        |
| `shopflow-wordmark.svg`                                | Full logo, transparent, for light surfaces    |
| `shopflow-wordmark-light.svg`                          | Full logo, transparent, for dark surfaces     |
| `shopflow-wordmark.png`, `shopflow-wordmark-light.png` | Transparent 1600-pixel-wide portfolio exports |
| `shopflow-mark-512.png`, `shopflow-mark-light-512.png` | Square 512-pixel icon exports                 |
| `favicon-32.png`                                       | Small browser icon                            |
| `apple-touch-icon.png`                                 | 180-pixel Apple touch icon                    |

`shopflow-preview.png` provides a warm-background logo preview for portfolio covers and repository headers.

The wordmark SVG lettering is outlined, so it does not require an installed font or an external font service. SVG is the preferred format for resizing. Use the light version on dark backgrounds so the name remains readable. Preserve the proportions and leave at least one quarter of the square mark's width as clear space around it. The transparent corners and backgrounds are intentional.
